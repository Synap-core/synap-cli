# Examples library

Concrete paste-ready rewrites and templates by category. Each file contains 3-5 fully-developed examples that you can adapt to a specific client dossier in 15-30 minutes.

Use this folder when:

- You are writing a rewrite for a specific field type and want to see how the best version reads.
- You need a fast budget anchor for a category you have not advised before.
- You want a template for the chat summary after delivery.
- You need to calibrate a Tranche structure with verifiable evidence.

Complement to `reference/14-worked-examples.md`. The reference doc explains the WHY of a rewrite. The examples folder gives you the WHAT to paste, by category.

## How to use

1. Open the file that matches the field you are rewriting.
2. Find the example category closest to your current client.
3. Copy the template.
4. Replace the placeholder fields with your client's specifics.
5. Run the 5-point QA check (zero em-dashes, zero "kill signature", named past dossier cited, named budget anchor, English in column D).

## Quality bar for examples in this folder

Every example here meets the standard we hold for client deliverables:

- Zero em-dashes (the long horizontal-line punctuation character).
- Zero internal jargon ("kill signature", "corpus", "doxxing depth").
- Specific, anchored claims (named past dossier, specific dollar amount, specific Soroban contract).
- Paste-ready English (column D rewrites).
- Length-calibrated (Q2 lands at 900-980 chars; Q6 lands at 900-980 chars; Q10 lands at 1700-1950 chars).

If you find an example that does not meet this bar, fix it and PR back to the skill.
