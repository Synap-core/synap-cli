## How to use this catalog

When you advise a client, name 2 or 3 past rejects whose pattern matches what worries you in the current dossier. Specific past failures are more persuasive than generic warnings.

Example client framing:
- *"The Q2 description currently uses 'earn rewards by attending events' language. Three past dossiers were rejected for the same framing: StellarRead at $150K, Stellar Nexus Experience at $60K, and EduAfrica Learning at $89K. The fix is to reframe the customer as the protocol (B2B) rather than the user (B2C earning), which the same kind of dossier, The Signal, used to win $121K."*
